Jurisprudence — recherche Judilibre

Recherche en texte intégral dans la base ouverte des décisions de justice (Cour de cassation, cours d'appel, tribunaux judiciaires) via l'API publique Judilibre. Vos requêtes partent directement de votre navigateur : aucune donnée ne transite par un serveur tiers.

Clé API : non configurée

1. Votre clé API Judilibre

L'accès à l'API nécessite une clé personnelle et gratuite, délivrée par le portail PISTE (créer un compte → créer une application en environnement PRODUCTION → souscrire l'application à l'API JUDILIBRE → copier l'« API Key »). La clé est conservée uniquement dans votre navigateur (stockage local) — elle n'est jamais publiée ni envoyée ailleurs qu'à l'API officielle.

Textes officiels (Légifrance) — facultatif non configuré
Limitation actuelle du portail PISTE. Les articles cités dans les décisions sont déjà cliquables sans rien configurer : ils s'ouvrent sur le site officiel Légifrance. En revanche, afficher leur texte directement dans cette page n'est pas possible : l'API Légifrance impose une authentification OAuth, et le serveur oauth.piste.gouv.fr répond « 403 Forbidden » à toute demande de jeton portant un en-tête Origin — que tout navigateur ajoute systématiquement. Ce refus est antérieur à toute vérification : aucun identifiant, si valide soit-il, ne peut aboutir depuis une page web. (L'API Légifrance elle-même accepte pourtant les appels de navigateur : seul le point d'authentification bloque.) Renseigner les champs ci-dessous n'aura donc d'effet que si PISTE lève cette restriction, ou si vous placez un relais côté serveur.

Le cas échéant : sur PISTE, souscrivez l'API Légifrance avec la même application, puis recopiez ci-dessous les identifiants OAuth de la fiche (« Client ID » et son secret). Comme la clé Judilibre, ils resteraient uniquement dans votre navigateur.

2. Recherche

Méthode : bien chercher, quel que soit le sujet
  1. Nommez la notion dans « Mots-clés » : « clause de non-concurrence », « trouble anormal de voisinage », « vice caché », « faute grave »…
  2. Expression exacte pour les formules figées du droit ; ET pour croiser des idées ; OU pour des synonymes.
  3. Appliquez un ou plusieurs angles d'analyse : ils transforment la recherche en cours (arrêts de principe, régime de la preuve, définition, actualité…) et se combinent — quel que soit le sujet.
  4. Affinez avec les filtres locaux, que l'API ne sait pas faire : mots à exclure pour écarter les notions voisines (ex. « sexuel » quand vous cherchez le harcèlement moral) ; mots exigés pour imposer un terme absent de la requête, vérifié dans le texte intégral de chaque décision affichée ; matière pour ne garder qu'un titrage (ex. « contrat de travail »).
  5. Prenez de la hauteur : « Analyser les résultats » donne la répartition par matière, juridiction, année et solution — et « Regrouper les résultats » réorganise l'affichage par thème.
  6. Repères : Bulletin = arrêts que la Cour juge importants ; sommaire/titrage = le langage officiel et normalisé de la Cour ; motivations = le raisonnement ; dispositif = ce qui est jugé.
  7. Pour une étude complète, recoupez plusieurs recherches (par ex. les formulations avant/après une réforme) et fusionnez les exports CSV.
