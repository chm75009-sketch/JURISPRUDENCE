Contrôler mon protocole préélectoral et le procès-verbal du scrutin

Déposez votre protocole ou votre procès-verbal

Le fichier est lu dans votre navigateur et n'est envoyé nulle part. Deux formats sont lus directement, .docx et .txt ; pour tout autre, ouvrez le document, copiez son texte et collez-le ci-dessous.

Les clauses, rédigées

Chaque clause est écrite en entier, avec les chiffres de votre entreprise dedans. Le bouton l'insère dans le document de l'onglet 3. Ce qui reste entre crochets vous appartient.

Le document et le calendrier

Votre texte est conservé mot pour mot. Les clauses insérées le suivent, dans l'ordre où elles se lisent. Le calendrier est calculé à rebours de la date du premier tour.
